# ¿Por Qué Falla?

Canal de YouTube en español que explica por qué fallan las cosas cotidianas.

Canal: https://www.youtube.com/@PorQueFallaYT

Política de privacidad: https://porquefalla-canal.github.io/privacy

Esta página es la página principal de la aplicación "Por Que Falla Uploader", una herramienta privada que usa el propio canal para subir sus vídeos.
