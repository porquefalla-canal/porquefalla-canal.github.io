# Política de privacidad

Aplicación: Por Que Falla Uploader (canal de YouTube ¿Por Qué Falla?).

Esta aplicación es una herramienta privada que usa únicamente el propietario del canal para subir sus propios vídeos a su propio canal de YouTube mediante la API de YouTube.

No recopilamos, almacenamos, compartimos ni vendemos datos personales de ningún usuario. La aplicación solo accede a la cuenta de YouTube del propietario del canal, con el permiso de subida de vídeos, y no ofrece acceso a terceros.

Las credenciales de acceso se guardan de forma cifrada como secretos privados del repositorio del propietario y no se publican.
